# Gearbox

Gearbox is a modern Flutter application designed as a blogging and social platform for car enthusiasts. Users can sign up, sign in, browse trending and latest blog posts, view blog details, interact with notifications, and manage their profile settings. The app features a clean UI, localization support, and a modular architecture using Riverpod for state management and Dio for networking.

## Key Features

- User authentication (sign up, sign in)  
- Browse and read blogs with trending and latest sections  
- Blog details with comments and likes  
- Notifications for user interactions  
- Multi-language support (English, Croatian)  
- Responsive and modern UI with custom themes  
- Modular code structure for scalability
